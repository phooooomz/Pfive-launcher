# Matriks izin

LX-LAUNCHER meminta tiga izin biasa yang tidak memunculkan dialog, dua izin LX Bridge yang baru dipakai saat pengguna menyambungkannya, satu layanan aksesibilitas opsional, ditambah tiga izin penyimpanan untuk File Manager. Tanpa LX Bridge izin itu tidak pernah diminta sendiri: pengguna mengetuk "Izinkan akses semua file" di File Manager, membaca penjelasannya, lalu Android membuka halaman izinnya. Dengan LX Bridge berjalan, LX memberi dirinya akses semua file lewat `appops set` tanpa bertanya, karena pemilik meminta File Explorer terbuka penuh seperti lewat ADB. Selebihnya akses diberikan lewat dialog sistem Android, satu per satu. Tidak ada `QUERY_ALL_PACKAGES`, `SYSTEM_ALERT_WINDOW`, atau akses notifikasi. `INTERNET` dipakai LX Bridge untuk alamat loopback saat menyalakan `lxdb` (`lxdb` sendiri tidak memakai jaringan), dan oleh Tedit untuk tiga hal yang dimulai pengguna: marketplace Open VSX setelah diizinkan, unduhan image Debian x86_64 dari GitHub, dan program yang dijalankan pengguna di dalam Debian.

Receiver `BridgeReceiver` tidak diekspor dan hanya menerima balasan notifikasi LX sendiri. `BridgeSetupService` diekspor untuk sistem saja, dilindungi `BIND_ACCESSIBILITY_SERVICE`. Komponen lain yang diekspor ada dua. `LauncherActivity` memang wajib untuk filter HOME dan LAUNCHER. `EmbedBinderProvider` hanya bisa dipanggil pemegang `INTERACT_ACROSS_USERS_FULL`, yaitu sistem dan shell, dan hanya menerima binder `lxdb` dengan tokennya. `onNewIntent` hanya memeriksa `ACTION_MAIN` dengan `CATEGORY_HOME` dan tidak membaca extras. `allowBackup` dimatikan.
