# LX-LAUNCHER 0.1.0

Rilis pertama. LX-LAUNCHER menjadikan layar Home Android sebuah desktop: workspace, dock, taskbar, widget, dan jendela yang bisa Anda atur sendiri.

APK release dikirim tanpa tanda tangan. Tanda tangani dengan kunci Anda sendiri lewat `apksigner` sebelum dibagikan. APK debug bisa langsung dipasang untuk mencoba.

## Memasang dan mencoba

1. `adb install lx-launcher-0.1.0-debug.apk`, atau pasang berkasnya langsung di perangkat.
2. Buka LX-LAUNCHER, lalu ketuk "Jadikan LX-LAUNCHER aplikasi Home" dan setujui di dialog Android.
3. Tekan Home. Usap ke atas untuk melihat semua aplikasi, tekan lama desktop untuk menambah widget.

Untuk kembali ke launcher lama: LX Settings, bagian Tentang, lalu "Kembali ke launcher sebelumnya".

## Diuji di

Waydroid dengan Android 13 (x86_64), di layar 1920x1028 dan dengan meniru layar ponsel 720x1600. Ponsel arm64 sungguhan, work profile, dan TalkBack masih perlu diuji.

## Yang masih kurang

Terminal, widget cuaca, judul lagu di widget media, dan beban CPU sistem. Aplikasi Android tetap memakai jendela Android sendiri.
